# Demo Music Files

Place your demo MP3 files here with the following names:

- `chill-vibes.mp3`
- `summer-nights.mp3`
- `midnight-drive.mp3`
- `ocean-waves.mp3`
- `city-lights.mp3`

These files will be used as demo tracks when no user music is uploaded.

## Recommended Free Music Sources:

1. **Free Music Archive** - https://freemusicarchive.org/
2. **Incompetech** - https://incompetech.com/music/
3. **Bensound** - https://www.bensound.com/
4. **YouTube Audio Library** - https://studio.youtube.com/
5. **ccMixter** - http://ccmixter.org/

## File Requirements:

- Format: MP3
- Size: < 10MB per file
- Quality: 128-320 kbps
- License: Creative Commons or Public Domain

## Note:

Make sure you have the rights to use any music files you place here.
The app will fallback to external URLs if local demo files are not found.
